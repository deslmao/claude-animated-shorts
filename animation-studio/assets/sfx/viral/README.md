# The owner's viral SFX pack

Curated and supplied by the owner (27 Nov 2026); copied here with descriptive names. Priority over every generic / ElevenLabs sound: `sound/build.py` looks in
`assets/sfx/viral/` first, normalises each file to a set level under the voice (`VIRAL_REL`), trims long ones (`VIRAL_MAX`) and fades them out; every `viral_*` cue
also ducks the music 8 dB (a "major" hit). Used in `stories/in-my-world-2.ts` (the `VIRAL` table).

Files: anime_wow, camera_flash, ding, error, fahhh, goofy_run, info_5, keyboard_typing, metal_pipe_clang, punch, punch_game, rizz, tmp7901, tuco_get_out, undertaker_bell, huh,
danger_alarm, ack, among_us_reveal, dun_dun_dun, bing_bing_bing, ender_pearl.

Rights note: several of these are well-known meme clips (a show's dialogue, a game's sound). On YouTube, TikTok and Instagram, copyrighted clips can trigger Content ID claims or
muted audio; the owner chose them. Not used in the first cut: danger_alarm, ender_pearl, tmp7901 (no fitting beat).
